# Fix Errors Benchmark

This benchmark evaluates the model's ability to fix broken code snippets in the ADK.

## `benchmark.yaml`

This file defines the benchmark cases. Each case points to a test file in the `tests/` directory that contains a complete, passing test.

## `verify_fix_errors.py`

This script validates the integrity of `benchmark.yaml`, ensuring that it is well-formed and that all referenced test files exist and contain the required placeholders.

## `tests/`

This directory contains the Python test files for the benchmark cases. Each file is a self-contained, passing `pytest` test. The code that should be generated by the AI is marked with a placeholder:

```python
# BEGIN: CODE
...
# END: CODE
```
