# Fix Error Benchmark Templates

This directory contains the Python test files that serve as templates for the `fix_error` benchmark suite. Each file in this directory corresponds to a benchmark case defined in `benchmark.yaml`.

## Structure

Each test file is a self-contained, passing `pytest` test. The code that should be generated by the AI is marked with a placeholder:

```python
# BEGIN: CODE
...
# END: CODE
```

The benchmark framework will remove the code between the markers and expects the answer generator to reproduce it.

## Usage

When a `fix_error` benchmark is run, the `PytestBenchmarkRunner` does the following:
1. Reads the content of the corresponding test file from this directory.
2. The code between `# BEGIN: CODE...# END: CODE` is extracted and used as the ground truth.
3. The benchmark orchestrator removes the code between the markers and sends the file content to the answer generator.
4. The runner replaces the empty `# BEGIN: CODE...# END: CODE` block with the code generated by the answer generator.
5. Writes the modified content to a temporary file.
6. Executes `pytest` on the temporary file.

If the test passes, the benchmark is considered a "pass." If it fails, the benchmark is a "fail."

To add a new `fix_error` benchmark, you would:
1. Create a new, passing test file in this directory with the code to be generated inside the placeholder.
2. Add a corresponding entry to the `benchmark.yaml` file, pointing to your new test file.
