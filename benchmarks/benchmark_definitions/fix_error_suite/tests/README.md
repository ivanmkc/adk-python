# Fix Error Benchmark Templates

This directory contains the Python test files that serve as templates for the `fix_error` benchmark suite. Each file in this directory corresponds to a benchmark case defined in `fix_error_benchmarks.yaml`.

## Structure

Each test file is a self-contained `pytest` test that is intentionally broken. The broken part of the code is marked with a placeholder:

```python
# BEGIN: CODE
# END: CODE
```

The benchmark framework injects the AI-generated code into this placeholder and then runs the test to see if the fix was successful.

## Usage

When a `fix_error` benchmark is run, the `PytestBenchmarkRunner` does the following:
1. Reads the content of the corresponding test file from this directory.
2. Replaces the `# BEGIN: CODE...# END: CODE` block with the code generated by the answer generator.
3. Writes the modified content to a temporary file.
4. Executes `pytest` on the temporary file.

If the test passes, the benchmark is considered a "pass." If it fails, the benchmark is a "fail."

To add a new `fix_error` benchmark, you would:
1. Create a new test file in this directory with a broken code snippet and the placeholder.
2. Add a corresponding entry to the `fix_error_benchmarks.yaml` file, pointing to your new test file.
3. Add the correct, working code to a corresponding file in `benchmarks/ground_truth/fix_error_suite/`.
