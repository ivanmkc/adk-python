# Google ADK Python: Definitive API Reference & Developer Guide

This document provides a comprehensive technical reference for the Google Agent Development Kit (ADK) Python framework. It covers the public API surface, class signatures, usage constraints, and best practices.

---

## 1. Core Architecture

The ADK architecture is built around three pillars:
1.  **Agents:** The definitional blueprints (identity, instructions, tools).
2.  **Apps:** The container for agents, plugins, and global configuration.
3.  **Runners:** The stateless execution engine that orchestrates the agent lifecycle.

### 1.1. Agents (`google.adk.agents`)

All agents inherit from `BaseAgent`.

#### `BaseAgent`
The abstract base class for all agents.
*   **Constructor:** `BaseAgent(name: str, description: str = '', sub_agents: list[BaseAgent] = [], before_agent_callback: BeforeAgentCallback | None = None, after_agent_callback: AfterAgentCallback | None = None)`
*   **Constraints:**
    *   **Name:** Must be a valid Python identifier (alphanumeric + underscore). **Cannot** be "user" (reserved).
    *   **Ownership:** An agent instance can only be added as a sub-agent to **one** parent. Attempting to add the same instance to multiple parents raises a `ValueError`. Use `agent.clone()` to create copies.
*   **Methods:**
    *   `run_async(parent_context: InvocationContext) -> AsyncGenerator[Event, None]`: The main execution entry point.
    *   `find_agent(name: str) -> BaseAgent | None`: Recursively searches for a sub-agent by name.
    *   `clone(update: dict | None = None) -> BaseAgent`: Creates a copy. **Cannot** update `parent_agent` or non-existent fields.

#### `LlmAgent`
The primary agent class for LLM-backed interactions.

*   **Constructor:**
    ```python
    LlmAgent(
        name: str,  # Required.
        model: str | BaseLlm = '',  # Required. E.g., "gemini-2.5-flash".
        instruction: str | InstructionProvider = '',  # Dynamic instructions.
        static_instruction: ContentUnion | None = None,  # Fixed/Cached instructions.
        description: str = '', # Critical for delegation (planner uses this).
        tools: list[ToolUnion] = [],  # List of tools.
        planner: BasePlanner | None = None,  # For 'thinking_config' or planning.
        input_schema: Type[BaseModel] | None = None,  # Pydantic CLASS.
        output_schema: Type[BaseModel] | None = None,  # Pydantic CLASS.
        output_key: str | None = None, # Save final output to session.state[key].
        include_contents: Literal['default', 'none'] = 'default', # 'none' = Stateless.
        generate_content_config: GenerateContentConfig | None = None,  # LLM params.
        before_model_callback: BeforeModelCallback | None = None,
        # ... callbacks
    )
    ```
*   **Critical Constraints:**
    *   **Tools:** Raw Python functions can be passed, but `FunctionTool` wrappers are preferred.
    *   **Schemas:** Always pass the class type (e.g., `MyModel`), never an instance.
    *   **Config:** `system_instruction`, `tools`, and `thinking_config` (via `planner`) belong in the agent constructor, **NOT** inside `generate_content_config`.
    *   **Statelessness:** Setting `include_contents='none'` prevents the agent from seeing conversation history (useful for stateless tasks).

#### `SequentialAgent`
Executes a list of sub-agents in strict order.

*   **Constructor:** `SequentialAgent(name: str, sub_agents: list[BaseAgent], ...)`
*   **Constraint:** Does **NOT** accept `tools`.
*   **Behavior:** Duplicate sub-agent names are allowed at runtime, though uniqueness is best practice.

#### `ParallelAgent`
Executes multiple sub-agents concurrently.

*   **Constructor:** `ParallelAgent(name: str, sub_agents: list[BaseAgent], ...)`
*   **Constraint:** Does **NOT** accept `max_workers` (managed automatically).

#### `LoopAgent`
Repeats execution of sub-agents.

*   **Constructor:** `LoopAgent(name: str, sub_agents: list[BaseAgent], max_iterations: int | None = None, ...)`
*   **Constraint:** `max_iterations` defaults to `None` (infinite loop) if not specified.

### 1.2. Application (`google.adk.apps.App`)

*   **Constructor:**
    ```python
    App(
        name: str,
        root_agent: BaseAgent,
        plugins: list[BasePlugin] = [],
        # ... configs
    )
    ```
*   **Validation:** `extra='forbid'`, so passing unknown arguments (like `agents` instead of `root_agent`) raises `ValidationError`.

### 1.3. Runner (`google.adk.runners.Runner`)

*   **Constructor:**
    ```python
    Runner(
        app: App,  # Mutually exclusive with agent/app_name
        # OR
        agent: BaseAgent,
        app_name: str,
        # ... services
    )
    ```
*   **Methods:**
    *   `run_async(
      self,
      *,
      user_id: str,
      session_id: str,
      invocation_id: Optional[str] = None,
      new_message: Optional[types.Content] = None,
      state_delta: Optional[dict[str, Any]] = None,
      run_config: Optional[RunConfig] = None,
  ) -> AsyncGenerator[Event, None]`
    *   `run_live(
      self,
      *,
      user_id: Optional[str] = None,
      session_id: Optional[str] = None,
      live_request_queue: LiveRequestQueue,
      run_config: Optional[RunConfig] = None,
      session: Optional[Session] = None,
  ) -> AsyncGenerator[Event, None]`
    *   `run_debug(
      self,
      user_messages: str | list[str],
      *,
      user_id: str = 'debug_user_id',
      session_id: str = 'debug_session_id',
      run_config: RunConfig | None = None,
      quiet: bool = False,
      verbose: bool = False,
  ) -> list[Event]`

#### `InMemoryRunner`
*   **Constructor:** `InMemoryRunner(agent: BaseAgent | None = None, app: App | None = None, ...)`. Stores state in RAM (lost on exit).

## 3. Tools (`google.adk.tools`)

*   **`FunctionTool`** (`google.adk.tools.function_tool`):
    *   Constructor: `FunctionTool(func: Callable, ...)` (Param is `func`, not `fn`).
*   **`GoogleSearchTool`**: Native grounding (modifies request, doesn't run python code).
*   **`OpenAPIToolset`**: Generates tools from OpenAPI specs.
#### `ToolContext` (`google.adk.tools.tool_context`)
```python

  tool_confirmation: Optional[ToolConfirmation]

  # Inherits load_artifact, save_artifact, get_artifact_version, list_artifacts from CallbackContext
```

## 7. Common Anti-Patterns

1.  **Misplaced Config:** `tools`/`system_instruction`/`thinking_config` in `generate_content_config` (Error).
2.  **Agent-as-Tool:** Passing `Agent` in `tools` list (Error). Use sub-agents.
3.  **Instance Schemas:** Passing `input_schema=User()` (Error). Use class `User`.
4.  **Orchestrator Tools:** `tools` in `SequentialAgent` (Ignored/Error).
5.  **Name Validation:** Agent names with hyphens/spaces (Error).
6.  **Shared Ownership:** Same agent instance in multiple parents (Error).
7.  **Runner Init:** Providing both `app` and `agent` (Error).
